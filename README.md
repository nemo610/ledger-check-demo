# Ledger Check / Commission Bot

Repositorio independiente para construir herramientas de automatización comercial y seguimiento de afiliados de forma transparente. No hay enlaces de afiliado activos ni ingresos garantizados hasta registrar programas, obtener aprobación y configurar enlaces propios.

El producto inicial se desarrollará en una rama aislada y se propondrá mediante pull request. No contiene claves, pagos ni servicios de pago.
